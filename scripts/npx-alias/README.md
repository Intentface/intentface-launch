# intentface-launch

The `intentface-launch` command, from [@intentface-launch/core](https://www.npmjs.com/package/@intentface-launch/core): product launch videos written as code, made with Claude Code.

```sh
npx intentface-launch init     # the same as: npx @intentface-launch/core init
```

`init` installs `@intentface-launch/core` in your product repo; after that, run the CLI as `pnpm launch` (or `npx intentface-launch`, which then uses the installed copy).

Documentation: <https://launch.intentface.com>
