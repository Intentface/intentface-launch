Intentface Launch turns a product launch video into code. Each video is a React
component made of shots. A renderer plays it frame by frame in headless Chromium
and encodes the frames with ffmpeg into a 1080p60 (or 4K) mp4.

[Intentface Launch, made with Intentface Launch](https://www.youtube.com/watch?v=psV-O07yDBg)

The video shows the product working: its real UI, captured from the running
app, close up and in its own look. You make it with Claude Code. You describe
the video, in one sentence or with screenshots, clips and music of your own;
Claude captures the product, sketches a storyboard you comment on in a local
studio, then builds and renders the final cut.

[The Intentface Events launch video, made with Intentface Launch from the running app](https://www.youtube.com/watch?v=wvBYZFLCv0Y)

## Start with Claude Code

Start your product's dev server, then run these from the product repo's root.
You need Node 22 or later and ffmpeg ([Requirements](/requirements)).

```sh
npx @intentface-launch/core init    # the package, a launch/ folder and the skills
pnpm launch setup                   # the browser renders use, once per machine
pnpm launch dev                     # the studio, at http://localhost:4400
```

Then open Claude Code in the repo and ask for a video:

> Look at my app and make a feature release video about our scheduling
> feature, 30 seconds.

Or let Claude do the setup too. Paste this into Claude Code in the product
repo:

> Set up Intentface Launch in this repo by following
> https://launch.intentface.com/quick-start.md, then make a 30 second launch
> video of my app.

Claude asks what sets the product apart, agrees a script with you and shows a
storyboard before it builds anything heavy. [Quick start](/quick-start) has
the details, including working from a checkout of this repo.

## Why code

- **Every frame is exact.** A frame is a pure function of its number, so any
  frame renders alone, in any order, in parallel, and the same every time.
- **The real product, not a mockup.** Videos import the product's own
  components and data, and captures record the running app.
- **An agent can do the work.** Shots, timing and copy are text that Claude
  reads, writes and checks against stills it renders for itself.

## Packages

| Package | What it is |
| --- | --- |
| [`@intentface-launch/core`](https://www.npmjs.com/package/@intentface-launch/core) | Engine, kit, CLI, studio and the skills Claude uses. Brand-neutral. |
| [`@intentface-launch/three`](https://www.npmjs.com/package/@intentface-launch/three) | 3D add-on: live UI on panels in space, real lens depth of field, soft light. |
| [`@intentface-launch/shaders`](https://www.npmjs.com/package/@intentface-launch/shaders) | Shader add-on: the Shaders library's WebGPU effects on the video's clock. |

A brand is an add-on too: a package with a team's fonts, logos and design, motion
and copy rules, which `pnpm launch add <package>` installs. Core is brand-neutral,
so a video takes its look from the product.
