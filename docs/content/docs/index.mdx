Intentface Launch turns a product launch video into code. Each video is a React
component made of shots. A renderer plays it frame by frame in headless Chromium
and encodes the frames with ffmpeg into a 1080p60 (or 4K) mp4.

The video shows the product working: its real UI, captured from the running
app, close up and in its own look. You make it with Claude Code. You describe
the video, Claude captures the product, sketches a storyboard you comment on,
then builds and renders the final cut.

## Why code

- **Every frame is exact.** A frame is a pure function of its number, so any
  frame renders alone, in any order, in parallel, and the same every time.
- **The real product, not a mockup.** Videos import the product's own
  components and data, and captures record the running app.
- **An agent can do the work.** Shots, timing and copy are text that Claude
  reads, writes and checks against stills it renders for itself.

## Packages

| Package | What it is |
| --- | --- |
| `@intentface-launch/core` | Engine, kit, CLI, studio and the skills Claude uses. Brand-neutral. |
| `@intentface-launch/three` | 3D add-on: live UI on panels in space, real lens depth of field, soft light. |

A brand is an add-on too: a package with a team's fonts, logos and design, motion
and copy rules, which `pnpm launch add <package>` installs. Core is brand-neutral,
so a video takes its look from the product.
